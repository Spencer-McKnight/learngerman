This project, Learn German, is an intelligent and creative tool designed by the user to teach anyone German.

Most language learning applications take you through modules, giving you repetitive tasks without catering to the unique learning speed and mind using it, and without considering the bleeding edge in methodology for language learning.

Learn German is better. It finds its method from advanced research that informs the progressions of linguistic understanding, particularly for German.

It utilises an intelligent technical stack, progressive deterministic probabilistic algorithms, to communicate a unique way of teaching language.

Features:

- written, listening, reading, comprehension, conversational and speaking are all considered.
- progressively discovers the current level of language proficiency, and adapts the current task to match just beyond the user's current abillity to always get correct.
- understanding of modern language, slang, abbreviations (i.e. the German spoken in Erlangen by ages 25+)
- matches with english as its teaching language, however focuses on only showing german wherever reasonable.

Technical Considerations:

- selecting intuitive and advanced package or technology choices that were researched and selected for the purpose of building this application's capacity.
- intelligent, defined algorithithmic driving
- abstracted at a level that allows modularity throughout the entire application
- database-enabled through supabase for advanced historical memory and algorithm

Research (read before building):

Ideas:

- Should be able to operate for free using inbuilt smarts or free technologies - it will originally be used via only a few people.
- Conversational or corrective capacity through advanced technology and active language processing.
- Modes, topics, etc.
- Advanced settings panel that allows modular selection of learning strategy by the user.
- Mobile-centric user interface to allow on-the-go learning.
- Aspects of reward through gamification to allow for a more fun experience of learning german.
